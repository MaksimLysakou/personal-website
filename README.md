# Personal website

Статический лендинг и блог. Python 3.10+; сторонние пакеты не нужны.

## Добавить статью

1. Скопируйте `content/blog/_template.html` в `content/blog/my-article.html`.
2. Заполните `data-title`, `data-description`, `data-date` (`YYYY-MM-DD`), `lang`.
3. Пишите обычный HTML внутри `<article>`. Заголовок `h1`, автор, дата и время чтения добавляются автоматически. В тексте используйте `h2`, `h3`, абзацы, списки, `pre/code`, цитаты и таблицы.
4. Для публикации замените `data-status="draft"` на `data-status="published"`.
5. Отправьте изменения в `master`: GitHub Actions проверит и соберёт сайт, затем опубликует его на GitHub Pages.

Адрес статьи: `https://maksim.lysakou.dev/blog/my-article/`. Имя файла используйте латиницей, в нижнем регистре, с дефисами. После публикации не меняйте его без перенаправления со старого адреса.

Дополнительно: `data-tags="AI, Engineering"`, `data-updated="2026-09-08"`. Картинки храните в `img/blog/`, вставляйте через `<img src="/img/blog/example.jpg" alt="Описание">`. Внутренние ссылки задавайте от корня сайта: `/blog/another-article/`. В примерах кода экранируйте `<` как `&lt;` и `&` как `&amp;`.

`_template.html`, файлы с начальным `_`, черновики и статьи с будущей датой не публикуются. Будущая статья появится при следующей сборке после наступления даты (UTC); автоматического расписания нет. Пока опубликованных статей нет, ссылка Blog отсутствует в меню, а пустая страница `/blog/` помечена `noindex` и исключена из sitemap. При удалении последней статьи ссылка снова исчезает; устаревшие страницы удаляются при пересборке.

## Локальная работа

```sh
python3 scripts/build_site.py --serve --drafts
```

Откройте http://127.0.0.1:4174/blog/. После правок обновляйте страницу — предпросмотр пересобирает сайт автоматически. `--drafts` показывает черновики и будущие публикации; все HTML-страницы такой сборки получают `noindex`. Никогда не публикуйте сборку с `--drafts`.

Для проверки только опубликованного контента:

```sh
python3 scripts/build_site.py --serve
```

Можно изменить порт: `--port 4180`. Сборка без сервера: `python3 scripts/build_site.py`. Результат — `_site/`; не редактируйте его вручную. Обычный сервер из корня репозитория не выполняет сборку блога, поэтому для локальной работы используйте команду выше.

## Проверки и индексация

```sh
python3 -m unittest discover -s tests -v
```

Сборка создаёт полноценные HTML-страницы, canonical, метаописания, Open Graph, BlogPosting JSON-LD, `robots.txt` и `sitemap.xml`. Ссылки и тексты статей доступны поисковым роботам без JavaScript. На хостинг попадают только готовые страницы и ресурсы; исходники статей, шаблоны и тесты не копируются.

После публикации проверьте:

- `https://maksim.lysakou.dev/robots.txt` и `/sitemap.xml` отвечают HTTP 200.
- В Google Search Console добавьте sitemap `https://maksim.lysakou.dev/sitemap.xml`.
- Через «Проверка URL» проверьте главную и опубликованные статьи; при необходимости запросите индексацию.

Доступность для робота и sitemap не гарантируют включения страницы в индекс. Точный статус Google показывает в Search Console.
